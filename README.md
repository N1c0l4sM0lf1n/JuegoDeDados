# Actividades Realizadas

1.- Se realizo un analisis para identificar las clases necesarias para este proyecto, siendo en este caso las clases Dado, JuegoDado y Calculadora.

2.- Estableci los Metodos y Atributos para las clases, para Dado tenemos el atributo caraSuperior, y los metodos lanzar y getCaraSuperior, para JuegoDado tenemos los atributos dado1, dado2 y calculadora, y los metetodos jugar y obtenerSuma, y finalmente para la clase calculadora solo tenemos el metodo sumar.

3.- En cuanto a las relaciones tenemos una composicion del Dado en JuegoDado y una asociacion con JuegoDado y Calculadora (Puede a llegar a ser una dependencia de JuegoDado a Calculadora)

4.- Luego se realizo el diagrama Uml que se encuentra entre los archivos del repositorio

5.- Y finalmente se codifico el programa en base a lo hecho en Visual Paradigm
